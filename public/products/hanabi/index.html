HANABI PLANNER

花火が人物・建物と「どこからどう見えるか」を、撮る前に確かめる。

Overview

打ち上げ位置と撮影地の関係から、花火が狙った構図にどう見えるかをシミュレーションします。感覚に頼らず、どこから・どの画角で撮れるかを事前に計画できます。

Features

  • 打ち上げ位置と撮影地から構図をシミュレーション
  • 号数・打上高・花火径・画角・焦点距離を反映した計画
  • 地形断面・稜線・障害物を踏まえた見え方の確認
  • Google Earth 連携で立体的に確認（追加機能）

System Requirements

本商品はブラウザで動作する Web アプリケーションです。PC・スマートフォンのいずれからでもご利用いただけます。

  • ご利用には、原則としてインターネット接続が必要です。
  • 地図表示、ログイン・認証、各種データ取得、外部連携などの機能は、オンライン環境を必要とする場合があります。
  • オフラインで利用できる一部機能があっても、すべての機能がオフラインで動作するわけではありません。
  • Google Earth 連携（追加機能）をご利用の際は、対応する外部ソフトウェア（Google Earth Pro 等）が別途必要です。
